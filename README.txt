FOCUS TIMER - APK STEPS
1. Unzip this folder.
2. Upload ALL files (keep the icons folder) to a free HTTPS host:
   - Netlify Drop: app.netlify.com/drop (drag the folder in), or
   - GitHub Pages / Cloudflare Pages.
3. Open the hosted link in Chrome on your phone: check it works and offers Install.
4. Go to pwabuilder.com, paste your link, press Start.
5. Package for Stores > Android > Generate. Download the zip, install the .apk file.
   (Allow "Install unknown apps" when asked.)
